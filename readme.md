# Leaves WebUI
Browser pages for my Leaves mods (item browser, config editor, load order, and the Questrandomizer, BarterEconomy, LootFuckery and Guild Stash pages). Not a gameplay mod; without it the mods work the same, you just don't get the pages.

## Requirements
- [Leaves-LeavesUtil](https://github.com/DeadLeavez/Leaves-LeavesUtil) ([latest release](https://github.com/DeadLeavez/Leaves-LeavesUtil/releases/latest)) - required.
